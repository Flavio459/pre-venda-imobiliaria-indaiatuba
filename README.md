# Pré-venda Imobiliária — Indaiatuba

Public applied-business project built with **Next.js + TypeScript**.

The repository explores how a focused B2B landing page can present a real-estate pre-sales proposition for the Indaiatuba market without mixing the public interface with private lead, CRM, WhatsApp or operational data.

## Live app

https://pre-venda-imobiliaria-indaiatuba.vercel.app

## Scope

This repository is intentionally narrow:

- public-facing landing page;
- responsive Next.js interface;
- business proposition presentation;
- deployment as a standalone web application.

It is **not** presented as a production CRM, lead-scoring engine, financial simulator or autonomous sales agent.

## Stack

- Next.js 14
- React 18
- TypeScript
- Vercel deployment
